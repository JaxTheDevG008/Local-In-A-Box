# Local In A Box

## Purpose
Local-first architecture is a type of software pattern where data is stored on the client's device rather than on a cloud server that collects your data and uses it to build an ad profile or improve their apps and whatnot. However, actually building apps with that architecture can be difficult, especially since you have to setup the database, conflict-free replicated data types (CRDTs), and more.

**LIAB is designed to solve that.** You can run `liab init` to setup your local-first project, `liab dev` to start a local-first environment, `liab doctor` to search for bugs, and so much more.
